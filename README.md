# Automated Scientific Researcher

构建可持续运行、可恢复、可复核的自动化科研系统。首个应用是电网运行样本探索与潮流求解方法研究。
用户设定研究方向和变量边界，智能体在范围内自主提出方法、执行实验并分析证据。

- [项目主设计](docs/PROJECT-DESIGN.md)：持续更新的目标、架构、研究变量、边界与待定事项。
- [Capstone 科学研究模式交接](docs/handoffs/CAPSTONE-SCIENTIFIC-RESEARCH-MODE.md)：工作台准备任务、双方接口和验收条件。
- [工作清单](docs/plans/WORKLIST.md)：交付范围和进度。
- [决策记录](docs/status/DECISIONS.md)：决定的原因与替代关系。
- [状态入口](docs/status/INDEX.md)：结构、日志和会话恢复。
- [原始任务书](docs/IEEE118_OOD_Sample_Expansion_Task_v2_2.md)：研究背景参考。

研发部署采用本机 OrbStack + Docker Compose。实际运行命令和验收证据随实现补充，以工作清单为准。
