# 研究摘要的首次真实模型验证

2026-11-04。使用现有ChatGPT订阅，在独立工程验证账本中完成两轮摘要缩写、分开会话复核和一个夸大反例。没有重跑研究实验，也没有把结果安装为运行时上下文。

## 实际观察

来源为团队冻结的中文接续研究报告，4548字符。两轮都能回查这份原文，第二轮另附第一轮摘要及其指纹，避免只对摘要再次摘要而失去依据。

| 检查 | 实际结果 |
| --- | --- |
| 第一轮正文 | 524字符；结构字段检查通过，新的会话给出接受意见 |
| 第二轮正文 | 460字符；仍保留七项指定事实，另一个新会话给出接受意见 |
| 正文夸大反例 | 固定字段保持正确，正文改为“独立验证通过、隐藏评价证明泛化、原分布无退化”；复核器明确拒绝，指出与原文及字段矛盾 |
| 来源引文 | 复核返回的引文均通过原文连续片段检查 |
| 运行收尾 | 全部6个模型进程已核查退出，预算预留为零，原始可见交流归档无记录缺口 |

两轮正常摘要都保留了：完整原输入仍有保管证据、额外实参凭证未记录、精确复现仅限共用宿主服务、独立外部训练/隐藏评价未完成、11.45倍原分布误差代价以及物理运行违规未消失。第二轮并非仅复制第一轮，正文进一步精简；变短本身不是通过依据。

生成和复核均使用`gpt-6.1-sol`，会话目录分开。这里的独立仅指复核会话没有参与生成并重新拿到原文，不能推断为不同模型、不同执行环境或外部科学验证。相同模型可能有共同盲点。

## 两次工程问题均保留

第一次生成在claims中增加了三项有来源的信息，但检查器要求固定字段集合。调用说明未明确这一区别，因此被结构检查拒绝。原输出及消耗保留。修订说明后，固定字段用于逐项核对，额外有依据的信息放在正文，未放宽事实核查。

第一轮三项有效模型调用完成后，收尾暂停命令因复用旧幂等键失败。全部输出已经落盘；外部只读核查进程退出后修复收尾、补回执，没有重复模型调用。已增加“恢复后再次收尾”回归检查。

## 这次尚未证明的能力

它验证了实际模型调用、来源绑定、分开会话复核，以及对一个明显夸大反例的识别。它没有覆盖长时间跨窗口、几十轮压缩、更多假说演进或复杂代码对象引用，也没有证明模型复核一定正确或七项保护项已穷尽所有重要信息。

核心仍把复核结果当作模型意见，`eligible_for_application=false`。自动采用、容量预警和Runtime安装未接通；接入时还需核查当前规则、任务和未决执行，不能只凭一次接受意见替换正在使用的上下文。
