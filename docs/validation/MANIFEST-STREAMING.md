# 附件清单流式解析验收

已移除附件清单的整份read_bytes/json.loads：逐事件解析整份JSON并计算完整SHA256，只保留项目/运行或实验身份和目标条目。文件版本与当前执行绑定仍在提交前核对。没有新模型请求、科学执行、清单总量上限或后台扫描。

新增固定依赖`ijson==3.5.1`，已更新pyproject.toml/uv.lock并执行`uv sync --locked --extra aar`。事件接口、读取缓冲及严格单文档解析行为依据[ijson官方文档](https://github.com/ICRAR/ijson)。本机后端为yajl2_c；代码没有强制切换后端或自行编写JSON词法。

8项专项检查通过，完整`uv run --extra aar python -m unittest discover -s tests -v`共671项，25环境跳过，其余通过。检查覆盖跨块Unicode、尾部空白及完整哈希、目标后非法内容/额外文档/无效编码/注释、重复字段/目标、缺失/畸形结构、实验对象选择、读取中改写和6万条清单内存回归。既有实际SDK安装中的事务外清单读取检查保留。

读到目标后仍继续解析到EOF，不能隐藏目标后的错误。对重复关键顶层字段、目标字段或目标条目明确拒绝；这是对歧义清单的收紧，不再采用字典最后覆盖或首个路径匹配。生成器产生的规范清单字段唯一；历史原件、旧回执和科学结果不改写。

本机合成清单内存对比，读取块沿用统一配置1MiB：

| 条目数 | 文件字节数 | 整份JSON峰值字节 | 流式峰值字节 |
|---:|---:|---:|---:|
| 1,000 | 111,866 | 473,773 | 1,167,356 |
| 60,000 | 6,937,866 | 29,496,261 | 8,757,835 |
| 120,000 | 13,937,866 | 59,110,117 | 8,757,828 |

计量为Python tracemalloc分配，不含原生解析器、进程RSS、页缓存和并发叠加。小清单可能因事件缓冲而比整份解析占更多内存；大清单峰值不随条目数线性增长。单个超长字符串、极深嵌套及目录核对清单仍可能增长，本项不提供任意负载常量内存保证。

复现：`uv run python scripts/manifest_memory_probe.py --output <新的结果文件>`。脚本只用临时合成文件，拒绝覆盖旧输出。日志、测量和源码指纹见`MANIFEST-STREAMING.json`及`artifacts/manifest-streaming-001/`。目录核对报告的条目存储/分页尚未实施。
