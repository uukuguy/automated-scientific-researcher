# Deep research

Frame the question, terminology, intended decision and unresolved assumptions from
the effective research contract. Distinguish discovering relevant work, reproducing
its results and establishing a new scientific claim. Choose a bounded investigation
that fits the available time, tool calls and resource budget.

Use search or retrieval tools only when the active runtime exposes them. Prefer
original papers, standards, official documentation and source implementations for
technical claims. Record the query, retrieval date, source author/title, version or
publication date, stable URL/DOI and the section/page or code revision supporting
an important claim. Mark inaccessible material and secondary summaries as such;
do not imply that a title or search snippet establishes the paper's result.

Search for alternative explanations, counterexamples and conflicting findings.
Compare problem definitions, data, assumptions, controls, numerical tolerances and
cost accounting before reconciling apparently inconsistent results. Explain why a
source applies to the present problem; citation count alone does not settle it.
Separate sourced observations, inference, uncertainty and proposed experiments.

A literature gap is not verified novelty, and a published benchmark is not ASR
validation evidence. Convert useful ideas into falsifiable hypotheses with cited
provenance and proposed observations; actual trial/evaluator references must come
from the research service. Preserve contradictory and negative findings.

When search is unavailable or the bounded investigation ends, report sources
actually inspected, unanswered questions and a concrete next query or experiment.
Never fabricate citations or claim a fresh literature search without one. This
skill provides a method, not a paid provider Deep Research service, search backend,
model subscription, API authorization or automatic delegation.

ASR-authored guidance; provenance is recorded in
